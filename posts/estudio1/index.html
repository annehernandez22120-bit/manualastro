Instala Node.js

Ი𐑼¿Qué es?

𖹭 Node.js es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador, directamente en tu computadora o servidor desde la terminal.

Ი𐑼¿Por qué Astro necesita a Node.js?

𖹭 Cuando ejecutas:

⤷ npm create astro@latest

o

⤷ npm run dev

quien realmente está ejecutando Astro es Node.js.

Ი𐑼¿En dónde puedo instalarlo?

𖹭 Sitio oficial de Node.js.ᐟ.ᐟ

Ი𐑼Verificación

𖹭 Luego de descargarlo, verifica que está instalado poniendo en la terminal:

⤷ node -v

⤷ npm -v

Y si lo está, saldran los números de la versión.
